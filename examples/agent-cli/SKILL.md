# agent CLI

Работай в контексте текущего продуктового проекта. Прочитай его применимые AGENTS.md / CLAUDE.md
и скиллы соответствующей операции. Каталог установки CLI не является рабочим проектом;
его AGENTS.md описывает сам CLI и не заменяет инструкции продукта.

Если рядом с этим файлом есть `references/personal.md`, прочитай его для личных предпочтений
и проектных дополнений. Установщик сохраняет этот файл при обновлении роутера.

Выбери только нужный встроенный процесс:

| Запрос | Скилл |
| --- | --- |
| Создать, продолжить сессию, отправить задачу, дождаться результата | agent-sessions |
| Взять, создать, подготовить, освободить слот; перенести локальные файлы | agent-slots |
| Разделить работу между исполнителями и собрать результаты | agent-orchestrate |
| Коммит по плану, частичные ханки | agent-commit |
| Закрыть законченные сессии, освободить память | agent-cleanup |
| Открыть, сохранить, перезапустить или закрыть Pen | agent-pen |
| Подключить скиллы, проверить зависимости, исправить установку | agent-setup |

Выполни `agent skills path <имя>` и прочитай полученный SKILL.md и нужные ссылки из него.
Не загружай все процессы заранее. Если команда `agent` не найдена, используй известный пользователю
путь установки или инструкцию установки пакета; не угадывай путь на чужой машине.

Процесс, проверки, формат коммита и закрытие задачи определяются продуктовым проектом.
Встроенные скиллы объясняют работу с CLI и восполняют отсутствующие инструкции.
Если проект явно требует другой способ доступа, сохрани этот выбор; конфликт уточни у пользователя.
Ошибку CLI сообщи с командой и кодом; изменение самого CLI — отдельная задача.

## Режим сессий

`agent sess create` по умолчанию запускает Codex chat (`superset sessions`);
терминальный Codex — с `--cli`, Claude — с `--agent claude`.
`--model` и `--mode` передаются в chat; в Superset 2.0.2 явный `--effort` для chat
недоступен (и `model[effort]` отвергается): опусти его для настройки пресета либо используй `--cli`.
Используй алиас, chat session id или terminal id из ответа; `anchor` передавай в `wait --after` как есть.
`resume` сохраняет `kind: chat|cli` из реестра; старые записи остаются терминальными.

При chat resume/send Superset может заменить session id и terminal id: CLI переносит алиас и keep. Используй новые id/anchor из ответа.
