# Pen

Этот процесс управляет окнами и сохранением. Для рисования используй доступный инструмент pen.dev
и скиллы дизайна текущего проекта.

```sh
agent pen ls --json
agent pen open <file.pen>
agent pen save <file.pen> --json
agent pen save-all --json
agent pen restart
agent pen quit
agent pen idle-check
```

Перед переключением на другой файл сохрани изменённый. CLI нажимает меню File › Save и проверяет mtime:
⌘S в Pen не работает. `verified: false` означает неизменившийся mtime: правок могло не быть или путь
окна неизвестен. Не выдавай это за подтверждённое сохранение; проверь путь и наличие правок.

restart сохраняет все окна, выходит и открывает те же файлы; дополнительные файлы — `--open`.
quit сначала сохраняет; код 9 означает, что файл нужен живой сессии.
Не обходи отказ через --force без поручения прервать такую работу.
idle-check без --apply показывает решение, с --apply закрывает ненужный Pen.

Нужны macOS и Универсальный доступ для приложения, из которого вызван CLI (например, Superset/Terminal).
Ошибка -1719 означает отсутствие разрешения; сообщи пользователю системный путь к настройке из ошибки.
Не повторяй клики бесконечно. `--dry-run` показывает AppleScript без нажатий.
После окончания работы закрой Pen, если он не нужен другим сессиям.
