# Сессии

Сначала `agent sess ls --json`: найди существующую сессию и тип агента. Используй алиас или полный id
терминала; префикс допустим от шести символов. Для дополнительного исполнителя подготовь отдельный
слот по [agent-slots](../agent-slots/SKILL.md); для нескольких — [agent-orchestrate](../agent-orchestrate/SKILL.md).

```sh
agent sess create --workspace <id> --prompt-file task.md --alias task-x
agent sess create --agent claude --workspace <id> --prompt-file task.md --alias task-x
agent sess send task-x --file followup.md --json
agent sess wait task-x --marker DONE-X --after <anchor> --timeout 45 --json
agent sess last task-x --json
agent sess resume task-x
```

`create` требует файл задания и по умолчанию выбирает Codex. Модель и effort необязательны:
опусти их для настроек пресета Superset. Не передавай модель одного провайдера другому.
Сохрани id терминала, алиас, workspace, тип агента и session id из ответа.
Общий лимит по умолчанию — пять сессий обоих типов на машине; код 8 означает его достижение.

`send --json` возвращает непрозрачный `anchor`: передавай его в `wait --after` без разбора.
Код 7 означает отсутствие подтверждения, но сообщение могло дойти. Не посылай его повторно:
проверь `last` или `wait` без `--after`. Маркер — текст `[[DONE-X]]` в ответе ассистента;
заранее включи его в задание. Для первой задачи, переданной через create, жди без `--after`.

Разбирай код выхода:

- 0 — маркер найден; проверь сам результат и заявленные проверки.
- 2 — таймаут; продолжи ожидание, если работа ещё идёт.
- 3 — требуется ответ или разрешение: прочитай `waiting.kind`, `text`, `options` и экран.
  На вопрос отвечай через `send --force` выбранным номером или текстом; разрешение на действие
  передавай только в пределах уже имеющегося полномочия пользователя.
- 4 — ход закончен без маркера; прочитай ответ, не считай это автоматически успехом.
- 5 — ошибка API в журнале; 6 — живой сессии нет.

`send` ожидающей разрешения сессии и `close` работающей требуют `--force`;
это не основание автоматически обходить ожидание или прерывать работу.
Жди короткими интервалами, чтобы сообщать пользователю о результате и блокерах.

`resume` сохраняет провайдера из реестра; старые записи без типа считаются Claude.
Неизвестный session id — Codex по умолчанию, нужен `--workspace`; для Claude добавь `--agent claude`.
Закрытие с сохранением и уборка описаны в [agent-cleanup](../agent-cleanup/SKILL.md).

CLI читает основной журнал открытого процесса, а не самый новый файл в каталоге.
Для Codex нужны `lsof` и единственный открытый основной rollout; ephemeral-сессии не поддерживаются.
Не угадывай журнал по cwd, дате или журналам подагентов. Сессия вне Superset видна в списке,
но без терминала отправить ей сообщение нельзя. Подробности — [README](../../README.md#как-sess-находит-журнал).
