# Уборка

```sh
agent sess ls --json
agent sess gc --project <project> --json
agent sess gc --project <project> --apply --json
```

Сначала прочитай план gc: какие сессии и панели закроются, что произойдёт с локальными файлами и Pen.
Без --project используется текущий проект; несколько можно передать через запятую.
Применяй в пределах поручения пользователя на уборку, учитывая дополнительные правила продукта.
Не закрывай соседние проекты, чтобы уменьшить число сессий.

gc закрывает idle-сессии с DONE-маркером или без активности дольше --idle (по умолчанию 30m),
завершившиеся терминалы, пустые шеллы и панели. Не трогает работающие, ожидающие ответа/разрешения,
с вопросом в последнем ответе, keep и текущую сессию. Если журнал не определён, сессию оставляет.
Не обходи эти ограничения только ради освобождения памяти.

Для отдельной завершённой сессии: `agent sess close <alias> --note "состояние работы"`.
CLI сохраняет тип агента и session id для resume, закрывает панель и убирает пустые панели workspace.
Прерывание работающей сессии через --force требует явного поручения пользователя.
Чтобы сохранить ожидающую решения сессию: `agent sess keep <alias>`; снять — `agent sess keep --rm <alias>`.

После close/gc чистому слоту без сессий возвращается имя slot-N, его локальные файлы переносятся
в основную копию. Это не означает слияния ветки. Полное освобождение — `slot release` по
[agent-slots](../agent-slots/SKILL.md); не удаляй невлитую работу ради уборки.

gc закрывает ненужный Pen; `--keep-pen` сохраняет его. При самостоятельном закрытии Pen следуй
[agent-pen](../agent-pen/SKILL.md). Отчитайся о фактически закрытом и о том, что осталось с причиной.
