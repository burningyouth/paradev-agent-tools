# Уборка

```sh
agent sess ls --json
agent sess gc --project <project> --json
agent sess gc --project <project> --apply --json
```

Сначала прочитай план gc: какие сессии и панели закроются, что произойдёт с локальными файлами и Pen.
Без --project используется текущий проект; несколько можно передать через запятую.
Применяй в пределах поручения пользователя на уборку, учитывая дополнительные правила продукта.
Не закрывай соседние проекты, чтобы уменьшить число сессий.

gc закрывает idle-сессии с DONE-маркером или без активности дольше --idle (по умолчанию 30m),
завершившиеся терминалы, пустые шеллы и панели. Не трогает работающие, ожидающие ответа/разрешения,
с вопросом в последнем ответе, keep и текущую сессию. Если журнал не определён, сессию оставляет.
Не обходи эти ограничения только ради освобождения памяти.

Для отдельной завершённой сессии: `agent sess close <alias> --note "состояние работы"`.
Из слота можно без ID: `agent sess close --note "состояние работы"`. Сначала выбирается свой
агент/терминал, иначе единственная живая сессия workspace (по окружению или cwd). При нескольких
сессиях CLI откажет — укажи ID/алиас, не закрывай соседей ради освобождения слота.
CLI сохраняет тип агента, `kind: chat|cli` и session id для resume. Chat закрывается через `sessions close`; в терминальном режиме CLI закрывает панель и убирает пустые панели workspace.
Прерывание работающей сессии через --force требует явного поручения пользователя.
При поручении закрыть себя работающему агенту нужен `agent sess close --force --note "…"`.
Самозакрытие выполняет отдельный worker, чтобы закрытие панели не оборвало уборку и sync-back.
Ответ `status: queued` подтверждает запуск; итог — в JSON `resultFile` (`status: closed` или `error`).
Не сообщай об успешном завершении закрытия по одному `queued`.
Чтобы сохранить ожидающую решения сессию: `agent sess keep <alias>`; снять — `agent sess keep --rm <alias>`.

После close/gc чистому слоту без сессий возвращается имя slot-N, его локальные файлы переносятся
в основную копию. Это не означает слияния ветки. Полное освобождение — `slot release` по
[agent-slots](../agent-slots/SKILL.md); не удаляй невлитую работу ради уборки.

gc закрывает ненужный Pen; `--keep-pen` сохраняет его. При самостоятельном закрытии Pen следуй
[agent-pen](../agent-pen/SKILL.md). Отчитайся о фактически закрытом и о том, что осталось с причиной.


## Завершение собственной задачи

Если процесс продукта и личное правило разрешают завершение задачи с освобождением слота:

1. Выполни проверки, согласованные commit/push/PR и другие действия закрытия по продукту.
2. Вместо отдельного project release/slot release используй finish: проектный `slot.release`
   должен быть подключён конфигурацией agent-cli, если продукт требует свой скрипт.
   Если hook не подключён, сначала разреши эту конфигурацию, не подменяй проектный шаг встроенным.
3. Сохрани итог (результат, проверки, коммиты, PR если есть, следующий шаг) вне Git-слота.
4. Последней командой вызови `agent sess finish --release-slot --summary-file /absolute/outcome.md --json`.
5. Отправь финальный ответ с итогом, `resultFile` и буквальным `receipt` из ответа команды.
   Не жди worker в этом же чате: он ждёт завершённый финальный ответ. Не называй queued успехом.

Работает только для точного собственного Superset chat. ID и --force не принимает.
Новый запрос, approvals, изменение задачи/слота или отсутствие receipt оставляют чат открытым.
Другая сессия, dirty Git или ошибка release блокируют освобождение. Worker ждёт native exit,
проверяет Git/Superset, пишет долговечный JSON и системное уведомление; после этого завершается.
Читайте результат через `agent sess finish --result /path/result.json --json`.
Только completed подтверждает полный успех; close.status и release.status различают частичный итог.
Если Git уже detached, повторный project release пропускается, остаются перенос файлов и имя Superset.
Сам запрос коммита, обычный конец хода или ожидание публикации не означают закрытие задачи.
Подробности и ограничения — [README](../../README.md#sess-finish-завершить-свою-задачу-и-освободить-слот).
