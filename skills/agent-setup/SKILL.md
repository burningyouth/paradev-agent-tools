# Подключение

Установи команду через `node bin/agent.js install` из [руководства по CLI](../../docs/cli.md#установка). Требуется Node.js 22+.
Для настройки исполнителя из Paradev Agent Tools используй `executor_install` с предпросмотром.
При работе с CLI подключай процессы и хуки отдельными командами.

```sh
agent skills install --agent codex --dry-run
agent hook install --agent codex --dry-run
agent doctor --json
```

После проверки повтори нужные команды установки без `--dry-run`. Для Claude используй `--agent claude`.
Без `--agent` команда `agent skills install` предлагает выбор в интерактивном терминале.
Codex по умолчанию: `~/.agents/skills`. Claude: `$CLAUDE_CONFIG_DIR/skills` или `~/.claude/skills`.
В Codex при Hooks need review подтверди новые определения и открой новую сессию. В чате Superset команды `/hooks` нет.

Компонент skills устанавливает только короткий `agent-cli/SKILL.md`. Он выбирает процесс через `skills path`;
встроенные инструкции обновляются вместе с пакетом. Операции skills не требуют Superset или
исправного пользовательского конфига. Не переходи в каталог установки для выполнения задач продукта.

При конфликте сначала просмотри текущий файл и --dry-run. Явный --force заменяет роутер с бэкапом
в `~/.agent-cli/backups/skills` (или AGENT_CLI_HOME); `references/` остаётся на месте.
Личные дополнения можно хранить в `agent-cli/references/personal.md`: роутер читает их, если файл есть.
Повторная установка одинакового роутера ничего не меняет. Симлинки в назначении не перезаписываются.

Убирай старые дубли только после проверки нового подключения, с резервной копией и в пределах
поручения пользователя. В частности, проверь прежний `~/.codex/skills/agent-cli` при переходе на
`~/.agents/skills`. Установщик сам чужие скиллы не удаляет. Перезапусти сессию, если подключение не видно.

doctor проверяет зависимости и наличие роутеров без входа в аккаунты и изменений настроек.
Он не доказывает готовность пресетов Superset, доступ к журналу конкретного процесса или
Универсальный доступ. Проверяй нужную команду в рабочем окружении после исправления найденной причины;
не создавай пробную сессию или слот без необходимости.

Проектные процессы, разрешения на коммит и внешние действия не задаются установщиком.
Подробнее — [подключение процессов](../../docs/skills.md).
