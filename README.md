# Paradev Agent Tools

Плагин для Codex и OpenCode, который управляет рабочими слотами и сессиями Paradev из чата. Можно выделить отдельный слот, поручить задачу исполнителю Codex или Claude, передать уточнение и проверить результат.

## Установка

1. Запустите Paradev и откройте в нём свой Git-проект.
2. Распакуйте готовый архив для своей платформы. Node.js уже входит в комплект.

   | Платформа | Архив | Установщик |
   | --- | --- | --- |
   | macOS на Apple Silicon | `paradev-agent-tools-<версия>-macos-arm64.zip` | **Paradev Agent Tools.app** |
   | Linux x64 | `paradev-agent-tools-<версия>-linux-x64.tar.gz` | **Setup.sh** с Zenity |

3. На macOS нажмите **Подключить Codex** или **Подключить OpenCode**. На Linux выберите клиент в `Setup.sh`. Если Codex потребует завершить установку через каталог Plugins, окно подскажет, какой каталог выбрать.
4. Перезапустите клиент, откройте новый чат в папке проекта и напишите **«Проверь статус этого проекта через Paradev Agent Tools»**. В ответе будут рабочее пространство, ветка и состояние слота.

При сборке из исходников готовые архивы появляются в `dist/`. Установка без Zenity, вариант для Windows через WSL2, обновление и диагностика описаны в [руководстве по подключению](docs/multi-agent-mcp.md).

## Работа из чата

| Что нужно | Что написать |
| --- | --- |
| Делегировать задачу | «Возьми отдельный слот и запусти Codex для этой задачи». |
| Уточнить поручение | «Передай в эту сессию уточнение и дождись ответа». |
| Получить результат | «Покажи последние ответы и изменения по этой задаче». |
| Завершить работу | «Сохрани итог, закрой сессию и проверь освобождение слота». |
| Проверить уборку | «Покажи, какие завершённые сессии и слоты можно освободить». |

Агент подбирает инструменты и связывает действия с конкретной сессией. Для коммитов и уборки плагин показывает план перед применением. Если соединение с хостом пропало, в установщике доступна кнопка **Проверить Paradev**. [Рабочие сценарии и инструменты плагина](docs/multi-agent-mcp.md#работа-из-чата)

## Расширения и разработка

Самостоятельный `agent` доступен для собственных скриптов, автоматизации и личных операций с Pen. Для проекта можно отдельно настроить хуки подготовки и освобождения слотов, перенос локальных файлов и правила коммитов. [CLI и расширения](docs/cli.md) · [Конфигурация проекта](docs/cli.md#agent-clijson)

Для разработки выполните `npm test`. `npm run build:mcp` собирает архив для текущей платформы. [Сборка и форматы поставки](docs/multi-agent-mcp.md#сборка-и-источники-форматов)
